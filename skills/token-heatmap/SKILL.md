# Token 热力图与战绩墙 (Antigravity Token Heatmap Cockpit)

调用 `open_token_heatmap` 打开可视化 Token 贡献热力图与 AI 工程研发战绩驾驶舱面板：
- **纯本地零上传**：仅只读解析 `~/.gemini/antigravity` / `antigravity-ide` / `antigravity-cli` 中的本地 `transcript.jsonl` 与会话元数据，并将匿名化统计缓存存于 `data/`。
